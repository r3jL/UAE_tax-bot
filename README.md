# Tax Bot

A collaborative project.

## Getting started

```bash
git clone https://github.com/jatin0129/tax-bot.git
cd tax-bot
```

## Workflow

Before you start working each session:

```bash
git pull
```

Work on your own branch, then open a Pull Request:

```bash
git checkout -b my-feature
# ...make changes...
git add .
git commit -m "describe your change"
git push -u origin my-feature
```
